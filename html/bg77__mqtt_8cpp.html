Detailed Description

Quectel BG77 LTE/MQTT driver implementation.

This file implements BG77 modem control through AT commands, including startup preparation, LTE network profile selection, MQTT open/connect/ subscribe/publish operations, inbound MQTT message queuing, and reconnection watchdog behavior.
