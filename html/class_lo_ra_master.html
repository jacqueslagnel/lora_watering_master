Detailed Description

Master-side LoRa P2P protocol controller.

LoRaMaster owns the SX126x radio event flow, node table, pending command queue, scheduled battery/status polling, and result publishing helpers. The class is intended to be driven from the Arduino loop() function by calling begin() once and loop() repeatedly.

Warning
The class keeps internal fixed-size buffers and node tables. Inputs that become frame payloads or queued text are truncated or rejected according to the implementation limits.
