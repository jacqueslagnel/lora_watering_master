Detailed Description

SIM7080 LTE/MQTT state machine.

The class owns modem serial I/O, PWRKEY control, network attachment, MQTT configuration and reconnection, a small inbound MQTT queue, and console command handling. The owner is expected to call begin() once and loop() repeatedly.
