Detailed Description

Confidential LTE/MQTT connection settings.

This file contains the credentials and network settings used by the LTE modem classes. It is explicitly marked as not intended for version control.

Warning
The values in this file grant access to the configured MQTT broker. Keep this file excluded from the source repository.
