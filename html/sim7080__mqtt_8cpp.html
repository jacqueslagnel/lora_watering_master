Detailed Description

SIMCom SIM7080 LTE/MQTT driver implementation.

This file implements SIM7080 modem control through AT commands, including startup preparation, LTE network profile selection, MQTT configuration, subscribe/publish operations, inbound MQTT message queuing, and reconnection watchdog behavior.
